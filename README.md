# 🍚 饮食计算器 Diet Calculator

基于 Monte Carlo 随机组合算法的一日三餐智能规划工具。输入身体数据，选择每餐候选食物，算法自动求解"吃多少克"。

**在线使用**：<https://my990813.github.io/diet-calculator/>

---

## 项目流程

### 1️⃣ 用户输入

| 输入项 | 说明 |
|--------|------|
| 年龄 / 身高 / 体重 / 性别 | 用于计算基础代谢 |
| 活动系数 | 久坐 1.2 ~ 高强度 1.725 |
| 目标 | 减脂（TDEE × 82%）或增肌（TDEE × 110%） |
| 蛋白质偏好 | 1.0 ~ 2.0 g/kg 体重 |
| 三餐热量比例 | 默认 3:4:3 |
| 三餐候选食物 | 每餐至少选 3 种，可从预设或 61 种食物库自选 |

### 2️⃣ 营养目标计算

```
BMR   = 10×体重 + 6.25×身高 − 5×年龄 + 5（男）/ −161（女）   # Mifflin-St Jeor
TDEE  = BMR × 活动系数
目标热量 = TDEE × 0.82（减脂）或 × 1.10（增肌）
目标蛋白 = 体重 × 蛋白偏好
目标脂肪 = 目标热量 × 28% ÷ 9
目标碳水 =（目标热量 − 蛋白×4 − 脂肪×9）÷ 4
```

微量营养素固定目标（中国居民膳食推荐量）：

| 指标 | 日目标 |
|------|--------|
| 维生素C | 100 mg |
| 叶酸 | 400 μg |
| 钙 | 800 mg |
| 维生素K | 80 μg（食物来源无上限，仅服华法林者需限制） |

### 3️⃣ 按餐分配 → 逐餐求解（solveMealTD）

每餐的热量/蛋白/脂肪/碳水/微量营养素目标 = 日目标 × 餐次比例。早餐先解，已用食物记入 `usedFoods`。

**每餐 MC 随机采样 500 次，取评分最高方案**：

```
for trial in 1..500:
  Step 1  随机抽 k 种食物（k = 3~7，加权随机 + 去重）
          跨餐硬排除：已被前面餐次用过的食物移出候选池
          强制补齐：确保含 蛋白源 + 碳水源 + 蔬菜（若候选里有）
  Step 2  热量平摊初值：每种食物 share = 该餐热量目标 ÷ 食物种数
  Step 3  份量钳制（clampQty）：
          - 不超过数据层单品上限（蔬菜 80~150g 等）
          - 单品不超过该餐热量的 40%
          - GI 限流：GI ≥ 70 限 100g（个计 1 个），GI 56~69 限 200g
            主食豁免白名单：米饭 / 面条 / 馒头
  Step 4  综合评分（越高越好）：
          + 营养达标奖励：热量/蛋白/VC/叶酸/钙/VK 贴近目标
          + 蔬菜多样性奖励：每多一种蔬菜 +6 分
          + 品类覆盖奖励：覆盖品类数 × 5
          − 偏差惩罚：热量 |Δ|×1.2、蛋白 |Δ|×3、碳水 |Δ|×2
          − 同类惩罚：非蔬菜类每多一种同类 −8 分
          − 跨餐重复惩罚：每项 −120 分
```

### 4️⃣ 结果展示

- **三餐卡片**：每餐食物 × 克数，实时小计
- **营养对比图表**：实际 vs 目标（热量/蛋白/脂肪/碳水）
- **九项营养体检**：总热量、蛋白质、脂肪、碳水、膳食纤维、VC、叶酸、钙、VK，逐项达标/偏低/偏高 + 建议范围
- **智能警告**：跨餐重复食物（米饭白名单除外）、营养不足时的食补建议

## 数据模型

每种食物 18 个字段（按每克或每份折算）：

```js
{id, name, icon, unit,        // 标识与计量
 cal, pro, fat, carb, fiber,  // 宏量营养
 vc, gi,                      // 维生素C、升糖指数
 folate, calcium, vk,         // 叶酸、钙、维生素K
 min, max,                    // 单品份量下限/上限
 cat}                         // protein | carb | veggie | mixed | dairy | fat | treat
```

食物库当前 **61 种**，覆盖蛋白源、碳水源、蔬菜、菌藻、水果、奶制品、混合食品（包子/饺子）等。

## 关键设计决策

| 问题 | 方案 |
|------|------|
| 用户三餐故意选同一食物 | 跨餐**硬排除**（候选池直接移除），软约束惩罚不够时从源头根治 |
| 餐内同一食物重复 | 加权随机池 shuffle 后按 id 去重 |
| 高 GI 食物过量 | clampQty 按 GI 分级限流，主食白名单豁免 |
| 蔬菜单品过量、种类单一 | 单品上限降至 80~150g + 蔬菜豁免同类惩罚 + 多样性加分 |
| 维生素K"超标"假警告 | 食物来源 VK 无毒性上限，max 设为 Infinity |
